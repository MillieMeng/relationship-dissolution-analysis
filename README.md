# Relationship Dissolution & Social Cognition Analysis

## Overview

This independent social cognition project examines psychological adjustment following relationship dissolution. It combines a quantitative survey of **119 participants** with qualitative interviews from **19 participants** to investigate relationships among attachment, rumination, and related psychosocial constructs.

The repository is designed as a reproducible, privacy-conscious research portfolio. It documents the planned analysis workflow and verified study-level results while excluding confidential participant records.

## Verified project facts

- Quantitative survey sample: **N = 119**
- Qualitative interview sample: **n = 19**
- Sampling adequacy: **KMO = .812**
- Internal consistency: **Cronbach's alpha = .891**
- ANOVA finding: **attachment anxiety was significantly associated with rumination**

No effect size, exact test statistic, degrees of freedom, p-value, regression coefficient, or model fit statistic is reported here because those values have not yet been verified against the final output.

## Research questions

1. How is attachment anxiety related to rumination following relationship dissolution?
2. Do the study scales demonstrate adequate reliability and factorability?
3. Which social-cognitive and emotional variables are associated with post-dissolution adjustment?
4. How do interview themes contextualize the quantitative patterns?

## Methods

The reproducible R Markdown template includes:

- data import and variable validation;
- missing-data and range checks;
- scale scoring and reverse-coding placeholders;
- Cronbach's alpha reliability analysis;
- KMO and exploratory factor analysis (EFA);
- ANOVA and regression templates;
- publication-ready visualizations; and
- export of tables and figures.

The qualitative interviews are described at the study level only. Transcripts, quotations, participant identifiers, and coding materials are not included.

## Data availability and ethics

**The real raw data are not public.** Survey responses and interview materials contain confidential participant information and are excluded from this repository. The analysis notebook defaults to a reproducible simulated dataset with the same broad variable structure—not the original observations. Simulated values must never be interpreted as study findings.

Anyone adapting this repository should place authorized local data in a non-versioned `data/` directory and confirm that sharing and analysis comply with the relevant consent, ethics, and data-governance requirements.

## Reproduce the template

1. Install R and RStudio.
2. Open `analysis.Rmd`.
3. Install the packages listed in its setup section.
4. Keep `use_simulated_data <- TRUE` to run the public demonstration.
5. Knit the notebook or run its chunks interactively.

To use authorized real data locally, set `use_simulated_data <- FALSE`, add `data/relationship_dissolution_data.csv`, and replace every placeholder variable name and scoring rule using the final study codebook. Review all output before reporting it.
